نبذة عن المشروع
المشروع هو نظام CRM عربي لإدارة علاقات العملاء، ويجمع جهات الاتصال والشركات والصفقات والمهام والتقارير داخل واجهة واحدة. يستخدمه فريق المبيعات لمتابعة العملاء والمبيعات والأنشطة وإدارة المهام وإنتاج تقارير الأداء.

التقنيات
اللغة: TypeScript وJavaScript وCSS
الإطار: Next.js 16.4.2 وReact 19.2.6
قاعدة البيانات: PostgreSQL
ORM: Drizzle ORM 0.45.2
التنسيق: Tailwind CSS 4.1.17
المنطقة: واجهة RTL عربية واتجاه تجربة الاستخدام من اليمين لليسار
تنظيم المشروع
الملف الوحيد الظاهر حاليًا هو أرشيف مضغوط crm-system-development.zip، يحتوي داخلـه على مشروع Next.js كامل:

Text
src/
  app/
    page.tsx          لوحة التحكم والإحصاءات
    layout.tsx        الهيكل العام والمظهر العربي RTL
    actions.ts        عمليات إنشاء وتعديل وحذف البيانات
    companies/        إدارة الشركات
    contacts/         إدارة جهات الاتصال وتفاصيلها
    deals/            لوحة Kanban والجدول لإدارة الصفقات
    tasks/            إدارة المهام والتكليف والمواعيد
    reports/          تقارير المبيعات والتصدير إلى CSV
    api/
      export/         تصدير الصفقات بصيغة CSV
      health/         فحص اتصال قاعدة البيانات
  components/
    AppShell.tsx      الشريط الجانبي والتنقل والبحث
    DealsBoard.tsx    عرض الصفقات بطريقة Kanban والسحب والإفلات
    forms.tsx         نماذج الشركات وجهات الاتصال والصفقات والمهام
    ui.tsx            عناصر واجهة مشتركة
  db/
    schema.ts         جداول الشركات وجهات الاتصال والصفقات والمهام والأنشطة
    index.ts          اتصال PostgreSQL عبر Drizzle
  lib/
    queries.ts        استعلامات لوحة التحكم والتقارير والبيانات
    seed.ts           إنشاء بيانات تجريبية عند التشغيل
    format.ts         تنسيق التواريخ والأرقام والعملات
كيفية عمله
يقوم AppShell بتحديد التنقل والبحث، بينما يجلب كل قسم البيانات من src/lib/queries.ts. يتم تنفيذ الإضافة والتعديل والحذف من src/app/actions.ts باستخدام Drizzle ORM، مع تحديث الواجهة وإعادة التحقق من الصفحة.

يدعم النظام أيضًا:

مراحل الصفقات: Lead وQualified وProposal وNegotiation وWon وLost
حالات جهات الاتصال: Lead وProspect وCustomer وChurned
ربط الأنشطة بالجهات والصفقات
مهام ذات تاريخ استحقاق وأولوية ومكلف
مؤشرات الأداء وقيم pipeline ونسبة الفوز والتقارير الشهرية
بيانات أولية تولّد تلقائيًا عند التشغيل
التشغيل
يتطلب المشروع PostgreSQL ومتغير البيئة DATABASE_URL.

bash
npm install
npm run dev
يقوم Next.js تشغيل التطبيق عادة على:

Text
http://localhost:3000
لاحظ أن المشروع موزع حاليًا داخل ملف ZIP؛ يُنصح بفك ضغطه وإضافته إلى المجلد الرئيسي للمستودع، وإلا لن يتعرف GitHub عادةً على المشروع أو manifest الخاص بـ npm مباشرةً من الواجهة.

أسئلة متابعة
ما الأقسام التي تعيد استخدام src/lib/queries.ts؟
هل توجد مصادقة وصلاحيات مستخدمين خارج واجهة المستخدم الظاهرة؟
هل تم إعداد نقل قاعدة البيانات (migrations) وتهيئة PostgreSQL بشكل كامل؟
